# 이용 안내서 — 지역사회보장 종합분석 플랫폼

이 문서는 서비스의 전체 사용 방법을 담은 안내서다. 화면 안에서도 상단 **“이용안내”** 메뉴에서
같은 내용을 볼 수 있다.

- 공개 URL: https://beaver21c.github.io/kihasa-indicator/
- 폐쇄망·USB 배포: `dist-single/index_embedded.html` 단일 파일 (더블클릭 실행)

---

## 0. 무엇을 하는 서비스인가

지역사회보장계획 수립·평가에 필요한 두 가지 작업을 한 화면 체계에서 처리한다.

1. **지표 분석** — 우리 지역의 지표값이 비교집단 대비 어디에 있는지, 어떻게 변해 왔는지 확인한다.
2. **GIS 지도 제작** — 내가 가진 통계값을 지도에 색으로 칠해 보고서에 넣을 이미지를 만든다.

입력 데이터는 **이용자 단말 안에서만 처리**되며 서버로 전송되지 않는다. 별도 설치 없이 브라우저에서 동작한다.

### 공통 개념 3가지

| 개념 | 설명 |
|---|---|
| **나의 지역** | 시·도 → 시·군·구 순으로 고르는 분석 대상 1곳. 모든 화면에서 빨강(◆)으로 강조된다. |
| **비교집단** | 우리 지역을 무엇과 비교할지. **광역(시·도) 내 / 시·군·구 7대 유형별 / 전국** 3종. |
| **7대 유형** | 광역도시형·일반도시형·대규모 제한도시형·소규모 제한도시형·도농복합형·대규모 농촌형·소규모 농촌형. 시·군·구 선택 시 배지로 표시된다. |

## 1. 지역중심 리포트 (`/region`)

시·군·구 1곳을 고르면 **19개 핵심 지표**를 한 화면에 박스플롯으로 펼친다.

**사용 순서**
1. 좌측에서 시·도 → 시·군·구 → 비교 기준 선택
2. 연도 선택
3. 화면에서 지표별 위치 확인 → 우측 하단 **PNG 저장**

**그래프 읽는 법**

| 표시 | 의미 |
|---|---|
| 🔴 빨강 다이아몬드 | 선택한 우리 지역 값 |
| 🔵 파랑 점 | 비교집단 평균 |
| 연파랑 박스 | Q1~Q3 (비교집단의 가운데 50%) |
| 회색 선 | Min~Max |
| 하단 숫자열 | Min · Q1 · 평균 · Q3 · Max · N(비교집단 규모) |

**알아둘 점**
- 영역 제목(인구·총괄·돌봄·건강·기타)을 누르면 **그 영역을 접거나 펼칠 수 있다.**
- 지표마다 생산 주기가 달라 선택 연도에 값이 없을 수 있다. 이때는 **그보다 앞선 가장 최근 연도 값**을
  자동으로 쓰고 지표명 옆에 `○○○○년 값` 배지를 붙인다.
- 원자료에 값이 아예 없는 지표는 `데이터 없음`으로 표시된다.

## 2. 지역맞춤 리포트 (`/custom`)

254개 전체 지표 중 **필요한 것만 최대 20개** 골라 같은 방식으로 비교한다.

**사용 순서**
1. 나의 지역·비교 기준 선택
2. 영역(시트)·연도·지표명 검색으로 목록을 좁힘
3. 체크박스로 지표 선택 (선택한 지표는 상단 칩으로 표시, `×`로 개별 해제)
4. **PNG 저장**

> 일부 지표는 특정 연도에 시·도 단위 값만 제공된다. 이 경우 비교 분포도 시·도 집계 기준으로 대체된다.

## 3. 연도별 추이 (`/trend`)

19개 핵심 지표의 연도별 변화를 본다. 비교 모드가 두 가지다.

| 모드 | 구성 | 언제 쓰나 |
|---|---|---|
| **단일 지역 vs 비교집단** | 우리 지역 실선 + 비교집단 평균 점선 + **Q1~Q3 음영밴드** | 우리 지역이 집단 안에서 어떻게 움직였는지 |
| **복수 지역 직접 비교** | 최대 5개 지역을 고정 색으로 겹쳐 표시 (+ 전국 평균 기준선 선택) | 인접·유사 지역과 직접 비교 |

**표시 옵션**
- 연도 범위(시작~종료) 지정
- 꺾은선 / 막대 전환
- **그래프 값 표시** 체크 → 점 위·막대 바깥에 숫자 직접 표기.
  켜면 **값 글자 크기 조절기(− 9 +)** 가 나타난다(4~20pt, 0.5pt 단위). 글자를 키우면 차트 높이가
  자동으로 늘어나 라벨이 잘리지 않는다.

**카드 확대**
지표 카드를 누르면 확대 모달이 열린다. 여기서
- 꺾은선/막대 재전환
- **두 번째 지표를 보조축(오른쪽 Y축)에 겹쳐보기** — 단위가 달라도 함께 볼 수 있다
- **연도별 수치표** 확인

## 4. 지표 지도 — 단계구분도 (`/indicator-map`)

지표 1개를 골라 전국 시·군·구를 계급색으로 칠한다.

**사용 순서**
1. 나의 지역·비교 기준 선택
2. 연도 → 영역·검색으로 목록을 좁힌 뒤 **지표 1개(라디오)** 선택
3. 좌측 **🗺 범위·배경·라벨**, **🎨 색상·계급** 그룹에서 표시 조정
4. **지도 PNG 저장**

**표시 옵션**

| 그룹 | 항목 | 선택지 |
|---|---|---|
| 범위·배경·라벨 | 표시 범위 | 나의 시·도(기본) / 전국 |
| | 배경 | 도형만(기본) / 배경 지도(OpenStreetMap) |
| | 라벨 | 지역명+값(기본) / 지역명 / 값 / 없음 |
| | 라벨 글자 | 4~20pt (− + 조절) |
| 색상·계급 | 색상 | 순차 9종 + 발산 2종 = **11종** (흑백 인쇄용 그레이 포함) |
| | 분류 방식 | 자연분류(Fisher–Jenks) / 등분위 / 등간격 |
| | 계급 수 | 4~7 |
| | 색 방향 반전 | 켜기/끄기 |
| | 계급 기준 | 전국 기준(기본, 지역 간 비교 유지) / 비교집단 기준(내부 대비 강조) |

**화면에 표시되는 정보**
- 나의 지역은 **굵은 빨강 테두리**로 강조되고, 상단에 **값 · 전국 순위 · 비교집단 내 순위**(내림차순)가 표시된다.
- 범례에 계급 구간과 **각 계급에 속한 지역 수**가 함께 나온다.
- 값이 없는 지역은 회색 + `데이터 없음`.

**주의**
- 특정 지표는 해당 연도에 시·도 단위 값만 있어 지도를 그릴 수 없다. 이때 목록에서 흐리게 비활성화되고,
  이미 선택된 상태라면 **“시·군·구 값이 있는 연도”** 를 안내한다.
- 표시 범위를 전국으로 바꾸면 229개 라벨이 겹친다. 글자를 5~6pt로 줄이거나 “값”만 표시하는 편이 읽기 쉽다.
- 배경 지도는 외부 타일 서버에 접속한다. 내부망·오프라인에서는 “도형만”을 쓸 것.

## 5. 지표 만들기 (`/builder`)

기존 지표에 없는 값을 직접 조합해 만든다. 산식은 한 가지 형태다.

```
값 = ( 분자 항목들의 합 ) ÷ ( 분모 항목 1개 ) × 단위조정 계수
```

분모를 비우면 분자 합산값 자체가 지표가 된다.

**사용 순서**
1. 좌측 목록에서 항목을 **드래그**하거나 **[분자] · [분모] 버튼**으로 배치
2. 지표 가칭 입력, 단위조정 계수 선택 (×1 / ×100 / ×1,000 / ×1만 / ×10만)
3. 아래에서 결과 확인 → **PNG 저장** 또는 **🔗 링크 복사**

**배치 중 실시간으로 보여주는 것**
- 산식 문장
- **공통 가용 연도**(선택한 항목들이 모두 가진 연도의 교집합)
- 최신 연도 기준 **평균 · 중앙값 · 범위 · 유효 지역 수**, 그리고 **데이터 없음 / 분모 0** 건수 구분
- 첫 항목을 고르면, 공통 연도가 없는 항목은 목록에서 **자동 비활성화**된다
- 표시 자릿수가 길거나 너무 작으면 **권장 계수**를 경고로 안내한다(진행은 허용)

**산출물**
- 연도별 추이 (우리 지역 실선 + 비교집단 Q1~Q3 밴드, 값 표시·글자 크기 조절 가능)
- 단계구분도 (지표 지도와 동일한 색상·라벨·범위 옵션)
- 모든 산출물에 **“이용자 정의(비공식)”** 표기와 산식이 자동 삽입된다

**🔗 링크 복사**
주소에 **값이 아니라 산식만** 담는다. 받는 쪽에서 주소만 열면 같은 지표가 재현되고,
데이터가 갱신되면 자동으로 최신값으로 계산된다.

### 5-1. 자연어로 지표 만들기 (선택)

화면 상단의 접이식 패널이다. 이용자 본인의 **Gemini API 키**를 넣으면 자연어 설명
(예: “노인 천 명당 노인여가복지시설 수”)을 산식·가칭으로 옮겨 아래 슬롯에 자동 배치한다.

- AI는 **산식 설계만** 담당한다. 계산·검증·시각화는 전부 브라우저에서 로컬 수행한다.
- 외부로 나가는 것은 **질의문과 지표 목록(공개 메타)뿐**이며, **지표 값 데이터는 전송하지 않는다.**
- 키는 HTTP 헤더(`x-goog-api-key`)로만 전달해 주소창·리퍼러·프록시 로그에 남지 않는다.
- 키는 기본 **세션 저장**(탭을 닫으면 삭제). “이 브라우저에 저장”을 켠 경우에만 유지된다.
- 존재하지 않는 항목은 자동 제외하고 경고한다. 모델은 실행 시점 목록에서 flash 계열 최신 안정판을
  자동 선택하고, 한도 초과(429)·지원 중단(404) 시 다음 모델로 전환한다.
- **키를 넣지 않으면 이 기능만 비활성화**되고 수동 빌더는 정상 동작한다(내부망 배포 시 자연 축소).
- 키 발급: https://aistudio.google.com/app/apikey

## 6. GIS 지도분석 (`/map`)

내가 가진 통계값을 읍면동·시군구 단위 지도에 칠하고, 기관 위치를 함께 표시해 PNG로 내보낸다.
(구 `rcssp_map` 서비스와 동일 기능)

화면 하단 진행 바에 현재 단계가 항상 표시된다.

### 단계 ① 보기 모드 · 지역

| 모드 | 표시 단위 | 데이터 행 수 | 활용 |
|---|---|---|---|
| 전국 → 시군구 | 시군구 255개 | 255행 | 전국 단위 격차 진단 |
| 시도 → 읍면동 | 시도 1개의 읍면동 | 약 200~600행 | 광역 시도 내부 분포 |
| 시군구 → 읍면동 | 시군구 1개의 읍면동 | 약 5~50행 | 기초자치단체 정밀 분석 |

- 시도 변경 시 시군구는 자동 초기화된다.
- 일반구가 있는 시(수원·성남 등)는 **“일반구 통합(시 단위)”** 선택지로 시 전체 읍면동을 한 번에 볼 수 있다.

### 단계 ② 데이터 입력

**(가) 엑셀 업로드 — 실무 주력 권장**
1. **양식 다운로드** → 현재 보기 모드 기준 xlsx 생성 (`입력양식` + `사용방법` 2개 시트)
2. **값 컬럼만** 입력 (지역코드·지역명은 매칭 키이므로 수정 금지)
3. 업로드 → 매칭 성공·실패 건수와 실패 상세가 표시됨

**(나) 직접 입력**
현재 보기 모드의 지역 목록이 표에 나온다. 값을 넣으면 즉시 지도 색이 갱신된다. 수십 건 이내·데모용.

미입력 지역은 회색으로 처리된다. 음수값도 허용된다(변화율·증감 지표).

### 단계 ③ 색상 설정

- **팔레트 6종**: YlOrRd(강조형) / Blues / Greens / RdYlGn(발산) / Spectral(발산) / Viridis(색각이상 친화)
- **분류 방식 3종**: 등간격 / 분위수(기본) / 자연단절(Jenks)
- **구분 단계**: 3~7 (권장: 분위수 5단계)

### 단계 ④ 기관 위치 표시 (선택)

- **좌표 직접(WGS84)** — 경도(124~132)·위도(33~39) 십진수가 이미 있는 엑셀 업로드. TM·미터 좌표 미지원.
- **주소 지오코딩** — 주소만 있는 엑셀을 올리면 **V-World** 또는 **카카오** API로 좌표 자동 변환.
  둘 중 하나만 넣어도 동작하며, 둘 다 넣으면 V-World로 먼저 찾고 실패분만 카카오로 재시도한다.
  입력한 키는 저장하지 않고 브라우저 메모리에서만 쓴다(새로고침 시 사라짐).

기관은 회색 ✕로 표시되고, 점에 마우스를 올리면 기관명·주소 툴팁이 나온다.
지도 우측 상단 **“기관명 표시”** 로 라벨을 켜고 끈다. **선택 지역 밖의 기관은 표시되지 않는다.**
코로플레스 없이 경계 + 기관 점만 출력하는 것도 가능하다.

### 단계 ⑤ PNG 내보내기

우측 상단 해상도(1x/2x/3x) 선택 후 **⬇ PNG**.

- OSM 타일 배경을 숨기고 흰 배경 + 폴리곤만 출력한다(보고서 삽입용).
- 좌측 상단 제목 박스(서비스명 + 지역명 + 모드 + 날짜), 좌측 하단 출처 워터마크, 우측 하단 범례가 자동 삽입된다.
- 파일명: `choropleth_{모드}_{지역}_{YYYY-MM-DD}.png`
- 보고서 인쇄 시 2x 이상 권장.

**↺ 리셋** — 모든 입력값·설정 초기화 (변경사항이 있을 때만 확인 대화상자).

## 7. 엑셀 양식 작성 가이드 (GIS 지도분석)

**작성 시 유의사항**
- 지역코드 컬럼은 **텍스트(@) 형식**으로 지정되어 있다 → 앞자리 0 손실 방지
- 값 컬럼만 입력한다
- xlsx 형식 유지 (다른 이름으로 저장 시 csv·텍스트로 바뀌지 않도록 주의)

**업로드 매칭 로직**
1. `adm_cd` 8자리 정확 매칭
2. 길이 4·7·9자리 → 자동 0 패딩 (4→5, 7→8, 9→10)
3. 행안부 10자리(`adm_cd2`) → 통계청 8자리 자동 변환

**오류 대응**
| 증상 | 조치 |
|---|---|
| “지역코드 컬럼 미발견” | 양식 재다운로드 후 재시도 |
| 매칭 실패율 50% 초과 경고 | 보기 모드와 양식 일치 여부 확인 (시군구 양식을 읍면동 모드에 올린 경우 등) |
| 지역코드 앞 0이 사라짐 | 엑셀 셀 형식이 “일반”으로 바뀐 경우. 양식의 지역코드 컬럼은 건드리지 말 것 |

에러 박스 안의 **“입력값 초기화 후 재시도”** 버튼으로 상태를 되돌릴 수 있다.

## 8. 자주 묻는 질문

**Q. 지도가 회색으로만 보인다.**
데이터를 아직 입력하지 않았거나(미입력=회색), 선택한 지표에 해당 연도 시·군·구 값이 없는 경우다.
지표 지도에서는 화면 상단 안내 문구를 확인할 것.

**Q. 인터넷이 안 되는 내부망에서 쓸 수 있나.**
쓸 수 있다. `dist-single/index_embedded.html` 단일 파일을 쓰면 데이터까지 파일 안에 들어 있다.
이 환경에서는 웹폰트와 OSM 배경 타일만 빠지고 나머지는 모두 동작한다. 지도 배경은 “도형만”을 쓸 것.

**Q. 엑셀 업로드 시 매칭이 0건이다.**
보기 모드와 양식이 어긋난 경우가 대부분이다. 현재 보기 모드에서 양식을 다시 받아 작성할 것.

**Q. PNG에 배경 지도가 안 나온다.**
GIS 지도분석의 PNG는 보고서 삽입용 클린 모드로, 타일 배경을 의도적으로 제외하고 폴리곤만 출력한다.

**Q. 모바일에서 좌측 패널이 안 보인다.**
GIS 지도분석 화면 좌측 상단의 햄버거 버튼(≡)으로 패널을 연다.

**Q. 인쇄하면 색이 다르게 보인다.**
모니터 sRGB와 인쇄 CMYK 차이다. 흑백 인쇄가 예정되어 있으면 지표 지도의 **그레이(흑백 인쇄)** 색상을 쓸 것.

**Q. 값이 음수여도 되나.**
된다. 변화율·증감처럼 양·음이 섞인 지표에는 발산형 색상(RdYlGn·Spectral 또는 지표 지도의 발산 2종)을 권장한다.

## 9. 산출 방식 유의사항 (보고서 인용 시)

- 지도의 계급 구간은 **분류 방식에 따라 달라진다.** 인용 시 **분류 방식·계급 수를 반드시 병기**할 것.
- 화면의 모든 “평균”은 시·군·구 **단순평균(unweighted)** 이며 시·도 공식 소계값과 산출 방식이 다르다.
- 비교집단 규모(n)는 화면에 표기되며, 해당 연도 결측 지역은 분모에서 제외된다.
- “지표 만들기” 산출물은 **이용자 정의(비공식)** 이다. 인용 시 산식과 출처를 함께 밝힐 것.
