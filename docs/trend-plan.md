# 연도별 추이 비교 틀 — 기획 구성안 (기록 보존)

> **[상태] 구현 완료 · 기획 시점 기록**
> 이 문서는 `/trend` 화면 착수 전에 작성한 설계 문서다. 기록 보존용으로 남겨 둔다.
> **현재 구현된 사양과 사용법은 [`user-guide.md`](user-guide.md) 3장을 볼 것.**
>
> 기획 이후 달라진 점
> - 가용 연도는 지표 메타(`years`)가 아니라 **실제 데이터가 있는 연도**로 산출한다.
>   원자료에 연도 키만 있고 내용이 빈 블록(`{}`)이 있어 그대로 쓰면 빈 차트가 나온다.
> - **그래프 값 표시** 토글과 **값 글자 크기 조절기**(4~20pt)가 추가됐다.
> - 카드별 차트 타입 오버라이드는 전역 토글 + 확대 모달 내 전환으로 대체했다.
>
> 아래는 기획 당시 원문이다.

---

> 지역사회보장지표 대시보드(`kihasa-indicator`)에 **연도별(2018~2024) 추이 비교** 기능을
> 추가하기 위한 설계 문서. 구현 착수 전 기획·결정사항 확정용.

## 1. 개요

- **신규 페이지** `/trend` (연도별 추이) 를 기존 `/region`·`/custom` 과 나란히 추가한다.
- **데이터 기반: 지역중심 19개 핵심지표** (`public/data/welfare_region.json` 의 `data_by_year`).
  - ✅ 19개 지표 전부 **2018~2024 완비** 확인됨 → **신규 데이터 빌드 불필요**, 프런트엔드 집계만으로 구현.
  - 지역맞춤(`welfare_custom.json`)은 254개 중 절반(126개)이 2022 단일값이라 연속 추이에 부적합
    → 1차 범위에서 제외. 향후 "연속연도 보유 지표만" 필터링으로 확장 여지 둔다.

## 2. 비교 모드 (토글 전환)

사이드바 상단 토글로 두 모드를 전환한다.

| 모드 | 구성 | 비교집단 밴드 |
|---|---|---|
| **A. 복수 지역 직접 비교** | 2~5개 시군구 선택 → 각 지역 = 고정 색상 선/막대 | 전국·비교집단 평균을 점선 기준선으로(선택) |
| **B. 단일 지역 vs 비교집단** | 1개 지역 선 + 비교집단(광역/유형/전국) 평균선 + **Q1~Q3 음영밴드** | 기본 ON |

- 모드 A 지역 **최대 5개** (색 구분 한계). 고정 색 팔레트로 지역별 색 일관 유지.
- 모드 B는 기존 박스플롯 리포트의 "1곳 vs 비교집단" 사고방식을 시계열로 확장한 형태.

## 3. 축 · 연도 · 차트 타입

- **X축 = 연도**, **Y축 = 지표값**.
- **연도 선택기**: 기본 2018~2024 전체. 시작~끝 범위 조정 또는 연도 다중선택 → X축에 즉시 반영.
- **차트 타입 토글: 꺾은선 / 막대**
  - 선: 추세 강조 (다지역·다연도에 적합).
  - 막대: 연도별 그룹막대로 지역 비교. *(연도 × 지역)* 조합이 커지면 복잡 → "적은 연도/지역" 비교에 권장(카드별 가이드 표시).
  - **카드별 개별 토글**: 전역 기본값 + 카드별 오버라이드 → "복수 지표를 서로 다른 그래프 형식으로" 요구 충족.

### 3.1 축 스케일 (지수화 없음 — 자동 가변)

- **지수화(2018=100)는 사용하지 않는다.** 원자료 값 그대로 표시한다.
- **지표별 Y축 자동 스케일**: 각 차트의 Y축 범위를 해당 지표의 값 분포(밴드 포함 min~max에 여유 패딩)에 맞춰 자동 산정한다. 단위(%, 원, 명)가 지표마다 다르므로 **지표 1개 = 차트 1개**가 원칙.
- **보조축(이중 Y축) 지원**: 한 차트에서 **두 지표를 서로 다른 형태(예: 지표1=막대, 지표2=선)** 로 겹쳐 비교할 때,
  - 왼쪽(주축)·오른쪽(보조축)을 **각각 독립적으로 자동 스케일**한다.
  - 즉 보조축도 그 지표의 값 분포에 맞춰 가변 — 두 지표의 단위/규모가 달라도 각자 적정 범위로 표시된다.
  - 이중축은 주로 **확대 모달**에서 활성(미니 그리드는 단일 지표 기본). "지표 겹쳐보기" 옵션으로 두 번째 지표 선택.

## 4. 레이아웃 (그리드 + 클릭 확대)

```
[사이드바]                          [메인]
 ⚙ 모드 A/B 토글               카테고리별 섹션(인구·총괄·돌봄·건강·기타)
 📍 지역 다중 선택(A, 최대 5)        └ 19개 미니 추이차트 그리드(2~3열)
    / 1곳 + 비교기준(B)
 📅 연도 범위/선택                  (카드 클릭 시)
 📈 선/막대 기본값                → 확대 모달:
 🖼 PNG 저장                         · 큰 차트 + 범례
                                     · 연도별 수치 테이블
                                     · 개별 선/막대 토글
                                     · 두 번째 지표 겹쳐보기(보조축 자동 스케일)
```

- **미니 카드**: 지표명·단위 + 작은 추이차트(모드 B면 Q1~Q3 밴드 포함).
- **확대 모달**: 큰 차트 + 범례 + 연도별 값 테이블 + 선/막대 토글 + 이중축 겹쳐보기.

## 5. 신규 / 재사용 컴포넌트

**재사용**
- `utils/dataLoader.js` → `loadRegion` (데이터 그대로 사용)
- `utils/stats.js` → `getCmpStats` · `calcStats` · `flattenSigungu` (연도 루프 호출)
- `components/Sidebar.jsx`, `components/Header.jsx`, `pages/Home.jsx` (네비·진입 카드 추가)
- `utils/png.js` → `saveReportPng`
- `utils/plot.js` (Plotly 래퍼), `utils/constants.js` (팔레트·색 토큰 추가)

**신규**
- `utils/trend.js` — `buildTrendSeries(indicator, years, mode, sggList, cmpMode)` → 연도별 시계열 + (모드 B) Q1~Q3 밴드 데이터. 메모이즈.
- `pages/TrendReport.jsx` — 상태·그리드 조립.
- `components/MultiRegionSelector.jsx` — 다중 지역 칩 선택(최대 5, 기존 `RegionSelector` 확장).
- `components/TrendChart.jsx` — 선/막대/Q1~Q3 밴드 + **이중 Y축 자동 스케일** 지원 Plotly 차트.
- `components/TrendCard.jsx` — 그리드 미니 카드(클릭 → 모달).
- `components/TrendModal.jsx` — 확대 차트 + 수치표 + 토글 + 겹쳐보기.

## 6. 권장 구현 순서

1. `utils/trend.js` 시계열 빌더 (로직 핵심, 데이터 검증).
2. `TrendChart` 단독 완성 (선/막대/밴드/이중축 자동 스케일 렌더).
3. 사이드바(모드·다중지역·연도·차트타입).
4. 그리드 페이지 + 미니 카드.
5. 확대 모달 + 수치표 + 겹쳐보기(보조축).
6. PNG 저장 · 라우트(`/trend`) · `Header`/`Home` 진입점.
7. 반응형 · 색 팔레트 · 접근성 마무리.

## 7. 확정된 결정사항

- 모드 A·B **둘 다 전환 가능**.
- 연도 **선택 가능**(범위/다중), 기본 2018~2024.
- 차트 타입 **선/막대 토글**(카드별 개별 가능).
- 모드 B에 **Q1~Q3 음영밴드** 표시.
- 레이아웃 **그리드 + 클릭 확대**.
- 복수 지역 **최대 5개**, 지역별 고정 색 팔레트.
- **지수화 안 함** — 원값 그대로, 지표별 Y축 자동 스케일.
- **두 지표 혼합(선/막대 다른 형태) 시 보조축(이중 Y축)도 각각 자동 가변 스케일.**

## 8. 향후 확장 여지 (1차 범위 밖)

- 지역맞춤(custom) 지표 중 연속연도 보유분 추이 편입.
- 지수화(2018=100) 옵션 — 필요 시 모달에 토글로 추가.
- 비교집단 내 순위 추이 보조 표시.
- 막대 모드 다연도·다지역 동시 시 그룹/누적 선택.
